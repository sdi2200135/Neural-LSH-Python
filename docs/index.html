Neural LSH

Learned Approximate Nearest Neighbor search — αντικαθιστώντας τις κλασικές hash functions με ένα εκπαιδευμένο νευρωνικό δίκτυο.

Python 3.8+ PyTorch KaHIP MNIST · SIFT

📖 Σχετικά με την Εργασία

Η παρούσα εργασία αποτελεί τη 2η Προγραμματιστική Εργασία του μαθήματος «Ανάπτυξη Λογισμικού για Αλγοριθμικά Προβλήματα». Υλοποιεί τον αλγόριθμο Neural LSH — μια learned εκδοχή του κλασικού LSH, όπου οι hash functions αντικαθίστανται από ένα MLP classifier που έχει εκπαιδευτεί να προβλέπει το partition label κάθε διανύσματος.

Η εργασία επεκτείνει την 1η εργασία (LSH, Hypercube, IVFFlat, IVFPQ σε C++) χρησιμοποιώντας τα ίδια datasets (MNIST, SIFT) και τις ίδιες μετρικές (QPS, Recall, AF) για άμεση σύγκριση.

🔀 Πώς Λειτουργεί

Ο αλγόριθμος λειτουργεί σε δύο φάσεις:

Build Phase — nlsh_build2.py

k-NN Graph → Symmetric Graph → KaHIP Partition → MLP Training → Save Index

Search Phase — nlsh_search2.py

Load Index → MLP Inference → Top-T Bins → Multi-Probe → Top-N

🏗️ Build Phase index

Κατασκευή k-NN graph, graph partitioning με KaHIP, εκπαίδευση MLP classifier και αποθήκευση index.

🔍 Search Phase query

Φόρτωση του index, MLP inference, multi-probe στα top-T bins και υπολογισμός μετρικών.

🛠️ Τεχνολογίες

PyTorch

MLP classifier, εκπαίδευση με CrossEntropyLoss και Adam optimizer.

KaHIP

Balanced graph partitioning με τη βιβλιοθήκη kaffpa.

NetworkX

Διαχείριση και έλεγχος συνέπειας του k-NN γράφου.

NumPy / SciPy

Αριθμητικές πράξεις, φόρτωση datasets, exact search.

Build Phase

Κατασκευή του index — nlsh_build2.py

1 Input

Το build δέχεται το dataset και τις παραμέτρους για k-NN graph, partitioning και MLP training.

ΠαράμετροςΠεριγραφήDefault
-dDataset (SIFT fvecs ή MNIST idx3)—
-iΦάκελος αποθήκευσης index—
-type"sift" ή "mnist"—
--knnΑριθμός γειτόνων για k-NN graph10
-mΑριθμός partitions KaHIP & MLP output100
--imbalanceΕπιτρεπτή ανισορροπία partitions0.03
--kahip_modeKaHIP mode (2 = STRONG)2
--layersΑριθμός κρυφών layers MLP3
--nodesΝευρώνες ανά hidden layer64
--epochsΕποχές εκπαίδευσης10
--batch_sizeΜέγεθος batch128
--lrLearning rate0.001
--seedSeed αναπαραγωγιμότητας1
--knn_method"bruteforce" ή "ivfflat"bruteforce

Βήματα φόρτωσης

  1. Parse argvΧρήση argparse για όλα τα flags.
  2. Set seedstorch.manual_seed(seed) και np.random.seed(seed).
  3. Redirect outputOutputLogger ανακατευθύνει το stdout στο nlsh_build_output.txt.
  4. Φόρτωση datasetΚλήση load_dataset(dataset, type) — load_fvecs για SIFT ή load_mnist για MNIST.

2 Build Phase — Πώς χτίζεται το index

Βήμα 1: k-NN Graph Construction

  1. build_knn_graph(args, method)Κλήση του C++ binary μέσω subprocess.run. Αν method="bruteforce" → -bruteforce_knn. Αν "ivfflat" → -ivfflat_knn -kclusters 100 -nprobe 5.
  2. Παραγωγή knn_output.txtΚάθε γραμμή: node: neighbor1 neighbor2 ...
  3. read_knn_graphParse του αρχείου → dict {node: [neighbors]}.

Βήμα 2: Symmetric Weighted Graph

  1. Αφαίρεση self-loops & duplicates[nb for nb in graph[u] if nb != u].
  2. Μέτρημα εμφανίσεων κάθε ακμήςedge_weights[tuple(sorted((u, v)))] += 1.
  3. Ανάθεση βάρουςweight = 2 αν η ακμή υπάρχει και από τις δύο πλευρές, αλλιώς weight = 1.
  4. check_graph_consistencyΈλεγχος ότι κάθε u→v έχει v→u με ίδιο βάρος.

Βήμα 3: CSR Format για KaHIP

  1. to_csr(adj, n)Μετατροπή adjacency list σε CSR format.
  2. Παραγωγή 4 λιστώνvwgt (βάρη κορυφών = 1), xadj (offsets), adjncy (flattened γείτονες), adjcwgt (βάρη ακμών).

Βήμα 4: KaHIP Partitioning

kaffpa(
    vwgt, xadj, adjncy, adjcwgt,
    m,                    # αριθμός partitions
    imbalance,            # π.χ. 0.03
    True,                 # suppress output
    seed, kahip_mode
)
# → edgecut, partition vector (labels 0..m-1)

Βήμα 5: MLP Training

  1. Προετοιμασία δεδομένωνX_data = data[:n_nodes], y_labels = partition. Μετατροπή σε tensors.
  2. Split 80/20Train/validation split μέσω TensorDataset και Subset.
  3. DataLoaderBatching με batch_size και shuffle για training.
  4. Device selectiondevice = "cuda" if torch.cuda.is_available() else "cpu".
  5. Δημιουργία MLPClassifierMLPClassifier(d_in, n_out=m, hidden=nodes, layers=layers).
  6. Optimizer + LossAdam(model.parameters(), lr=lr) και CrossEntropyLoss().
  7. train_modelTraining loop με forward, backward, step. Validation ανά epoch.

Αρχιτεκτονική MLP

Input(d_in) → Linear(d_in, hidden) → ReLU
            → (layers-1) × [Linear(hidden, hidden) → ReLU]
            → Linear(hidden, n_out)  # χωρίς softmax
Σημείωση: Το softmax εφαρμόζεται στο forward pass του search, όχι στο training, γιατί το CrossEntropyLoss το περιλαμβάνει εσωτερικά.

Βήμα 6: Αποθήκευση Index

  1. model.pthtorch.save({state_dict, input_dim, output_dim, hidden_dim, num_layers}, ...)
  2. partition.npyPartition labels κάθε point.
  3. inverted_file.npydict {part_label: [point_ids]}.

Βήματα φόρτωσης

  2. Φόρτωση datasetload_dataset(dataset, type) → data (n×d).
  3. Limit databaseΑν n > 70000: data = data[:70000] για δίκαιη σύγκριση με Assignment 1.
  4. Φόρτωση queriesload_dataset(query_file, type) → queries (Q×d).

2 Build Phase (Search)

Το search phase δεν χτίζει index — το φορτώνει έτοιμο από τον δίσκο (αποτέλεσμα του build phase).

3 Query Phase — Πώς βρίσκεις τους γείτονες

Για κάθε query:

Βήμα 1: MLP Inference

q_t = torch.tensor(qvec).unsqueeze(0)         # [1, d]
with torch.no_grad():
    logits = model(q_t)                        # [1, m]
    probs = F.softmax(logits, dim=1)           # [1, m]
    probs = probs.squeeze(0)                   # [m]

Βήμα 2: Multi-Probe — Επιλογή Top-T Bins

T = min(args.T, probs.shape[0])
top_probs, top_bins = torch.topk(probs, T)
top_bins = top_bins.numpy()

Βήμα 3: Union Candidates

candidates = set()
for b in top_bins:
    if b in inv_file:
        candidates.update(inv_file[b])
candidates = list(candidates)

Βήμα 4: Υπολογισμός Αποστάσεων

cand_vecs = torch.tensor(data[candidates], dtype=torch.float32)
q_single = q_t.squeeze(0)
dists = euclidean_distance(q_single, cand_vecs)    # [Ncand]

Βήμα 5: Range ή Top-N

if args.do_range_search == "true":
    mask = (dists <= R)
    final_ids = [candidates[i] for i in range(len(candidates)) if mask[i]]
else:
    Nreq = min(args.N, len(candidates))
    _, top_idx = torch.topk(-dists, Nreq)
    final_ids = [candidates[i] for i in top_idx.numpy()]

Βήμα 6: Exact Search (Brute Force)

  1. Υπολογισμός διαφορώνdiff = data - qvec (broadcasting).
  2. Τετράγωνα αποστάσεωνsq = np.sum(diff * diff, axis=1).
  3. Top-NΑν N >= len(sq): argsort; αλλιώς argpartition + sort.
  4. Τελικές αποστάσειςdists = np.sqrt(sq[idx]).
최적화: Χρήση np.argpartition αντί για πλήρες sort όταν N < n — O(n) αντί για O(n log n).

4 Μετρικές — AF, Recall, QPS

Recall@N

true_set = set(true_topN_idx)
approx_set = set(approx_ids)
recall = len(true_set.intersection(approx_set)) / float(N)

Average Factor (AF)

best_true_dist = true_topN_dists[0]
af_values = []
for aid in approx_ids:
    dist_a = np.linalg.norm(data[aid] - qvec)     # true distance
    af_values.append(dist_a / (best_true_dist + 1e-12))
avg_af = float(np.mean(af_values))                # 1.0 αν άδειο

QPS (ανά query)

total_time_for_query = t_approx + t_true
qps = 1.0 / total_time_for_query
Σημείωση: Το QPS στο Neural LSH περιλαμβάνει και τον χρόνο exact search — διαφορετικό από την Assignment 1.

Ανάλυση ανά Μετρική

🎯 Ακρίβεια (Recall@N)

Η 1η εργασία υπερέχει ξεκάθαρα:

  • IVFFlat: 0.99 στο MNIST, 0.97 στο SIFT
  • Neural LSH: μέγιστο 0.26 στο SIFT, 0.22 στο MNIST

📏 Ποιότητα Προσέγγισης (AF)

  • IVFFlat: 0.06-0.5 (εξαιρετικό)
  • LSH/Hypercube: 1.1-1.3 (καλό)
  • Neural LSH: ~2.5 (εκτός από παραλλαγές β = 1.10-1.17)

⚡ Ταχύτητα (QPS)

  • SIFT: Neural LSH = 24-38 QPS — ανταγωνιστικό με IVFFlat/Hypercube
  • MNIST: Neural LSH = 6-9 QPS — ταχύτερο από LSH/Hypercube

⏱️ Χρόνος Αναζήτησης

  • Neural LSH: 0.002-0.02s (πολύ χαμηλός)
  • Στο SIFT: συγκρίσιμο ή ελαφρώς ταχύτερο από IVFFlat
Συνολικό συμπέρασμα: Η 1η εργασία υπερέχει σε ακρίβεια (χάρη κυρίως στο IVFFlat). Το Neural LSH, παρότι υστερεί σε Recall και AF, προσφέρει σταθερή και ταχεία αναζήτηση με πολύ χαμηλούς χρόνους ανά ερώτημα. Καμία παραλλαγή δεν πλησίασε την απόδοση του IVFFlat, ο οποίος παραμένει η πιο αποτελεσματική μέθοδος ανάκτησης.

Παρατηρήσεις

  1. Το imbalance=0.03 δίνει καλύτερο AFΟι παραλλαγές β έχουν AF ~1.10 έναντι ~2.5 των άλλων.
  2. Το μεγαλύτερο T βελτιώνει το RecallΟι παραλλαγές γ (T=10) έχουν σχεδόν διπλάσιο Recall από τις α (T=5).
  3. Το πυκνότερο k-NN graph βοηθάknn=40 (συνδυασμός 5) δίνει καλύτερο Recall από knn=10.
  4. Το Neural LSH δεν φτάνει το IVFFlatΤο partitioning χάνει ποιότητα έναντι του k-means clustering.
  5. Πολύ χαμηλοί χρόνοι αναζήτησηςtApprox = 0.002-0.02s — ταχύτερο από LSH/Hypercube στο MNIST.
